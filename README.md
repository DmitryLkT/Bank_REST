## Описание
Веб-сервис для управления банковскими картами с разделением ролей пользователей и администраторов. 
Приложение обеспечивает безопасное хранение конфиденциальных данных с помощью шифрования AES, 
аутентификацию через JWT-токены и автоматическое управление статусами карт по расписанию. 
Сервис поддерживает пагинацию, фильтрацию, переводы между картами и полностью упакован в Docker для удобного развертывания.

## Функциональность
### Администратор
- Создает, блокирует, активирует, удаляет карты
- Управляет пользователями (блокировка/разблокировка)
- Видит все карты (поиск + пагинация
### Пользователь 
- Просматривает свои карты (поиск + пагинация)
- Запрашивает блокировку карты
- Делает переводы между своими картами
- Смотрит баланс

## Установка
### Клонировать репозиторий
```
git clone https://github.com/DmitryLkT/bank_REST.git
```
### Перейти в директорию
```
cd bank_REST
```
### Изменить переменные (при необходимости)
```
.env
```
### Запустить через Docker Compose
```
docker-compose up --build
```
